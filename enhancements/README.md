# Enhancements — M3

Default owner: M3.

This directory is for features selected by the whole team in `docs/EXTRA-FEATURE-PLAN.md` before implementation begins. These features are additional to the MVP and are developed/tested in parallel with M1/M2's MVP work.

Keep enhancement modules isolated where practical. The MVP must remain usable if an enhancement is disabled or unfinished. Coordinate contracts and integration points with M1/M2. Do not place required MVP business logic here.
